# Spiral of Deep Time

Earth's 4.2 billion years drawn as one line wound into a spiral, at 1 pixel per millennium. The spiral ends at 0 AD and continues as a straight strip to today at 1 pixel per decade, which is 100 times more magnified than the spiral. Pick a period from the dropdown to turn its stretch of the line gold.

A single static page: open `index.html`, no build step.
